# Accessibility

Target WCAG-informed mobile practices require validation with TalkBack and real users. Use semantic headings/roles, descriptive labels, announced errors/status, logical traversal, 48dp targets, font scaling, adequate contrast, non-color status cues and plain Vietnamese copy. Preserve user accessibility settings and support switch/keyboard navigation where practical.

Forms associate instructions/errors with fields and do not erase input. Timed content provides control. Loading indicators announce meaningful progress without repeated noise. Dialog focus is trapped and restored. AI drafts are announced as unverified suggestions; changes are reviewable.

Test at large font/display size, portrait/landscape where supported, TalkBack, grayscale/high contrast, reduced motion and interrupted network. Record issues, severity and evidence; do not claim accessibility conformance solely from automated checks.
