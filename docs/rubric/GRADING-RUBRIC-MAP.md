# Grading rubric map

This map plans evidence and does not predict a grade.

| Criterion | Points | Primary documents | Required artifact |
|---|---:|---|---|
| 1A Report structure | 0.50 | report outline/page budget/figure plan | formatted 40–60 page PDF |
| 1B Slides/video | 0.50 | demo script/submission checklist | 10–14 slides; 5–10 minute matching video |
| 2.1 Idea/problem | 1.00 | overview, personas, survey | real responses and analysis |
| 2.2 UI/UX | 1.00 | UI/UX, design system, Figma requirements | prototype + implemented state screenshots |
| 2.3 Android architecture | 2.00 | all mobile architecture docs | source tree, diagrams, tests, lifecycle demo |
| 2.4 Database/API | 1.50 | API, DB, mobile data/network | persisted CRUD and auth evidence |
| 2.5 AI | 2.00 | all AI docs | real gateway/provider call, safety/evaluation |
| 2.6 Testing | 0.75 | testing docs/evaluation | executed reports and state tests |
| 2.7 Git/team | 0.50 | project-management docs | history/issues/board/PR evidence |
| 2.8 Creativity/completeness | 0.25 | offline, observability, deployment | legitimate working enhancements |

Mobile and AI receive the largest report, implementation and demo allocation. Documentation alone is not implementation evidence.
